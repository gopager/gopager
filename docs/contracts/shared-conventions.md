# Shared Interface Conventions

[Contract index](../domain-contracts.md) | [Reference cases](reference-cases.md)

Referenced contracts (follow only when relevant): [C-01](c-01-transmission-acceptance.md), [C-05](c-05-matching-correction.md), [C-06](c-06-identity-authorization.md), [C-07](c-07-query-live.md), [C-08](c-08-events-jobs.md), [C-11](c-11-processing-presentation.md).

- Each operation identifies context, calling Principal/Gateway, domain input, result, and possible errors. Go uses cancellable context and the finite AP-02 limits below; AP-03 validates feasibility rather than silently inventing unlimited behavior.
- Server entity IDs are opaque UUID references serialized as strings, immutable and never reused. The UUID generation version is not a domain contract. Addresses/Functions are Protocol data, not server IDs. Submission IDs are Gateway-owned opaque strings.
- Observation time, Acceptance time, rule Validity time, internal Message time, Contribution time/age anchor and View time are distinct. Grouping uses each offset-bearing Observation instant, not Unit matching. C-05 maintains shared Message contributions; C-07 derives one first-observed View time per result Message. Retained subsecond precision remains AP-03.
- Mutable configuration needs a visible revision/expected state for conflicts. Immutable Transmission evidence is not 'corrected' by updating it; derived data is versioned separately.
- Authentication is not authorization. Administrative, guest, Gateway, API-key, worker, and plugin paths require explicit capabilities. A technical worker is not a global data reader for outbound Payloads.
- Errors use the C-07 code/envelope catalog. Other users' IDs, secrets, and internal SQL/plugin errors do not belong in public details.
- English is the authoritative interface/documentation language. Define stable machine-readable error/status codes and structured Localized text parameters independently of localized display text. Any human-readable fallback is English; clients do not parse it. UI language and formatting locale do not change IDs, field names, enum/Domain event values, wire formats, or authorization.
- Atomicity applies within the authoritative database, not to browser state or external providers. Commit data and required domain outbox work together. Intermediate derivation must not be reported as complete state.
- Idempotency is operation-specific; it replaces neither AuthZ nor distinguishing independent Transmissions. Retention and ordinary restart must not unintentionally regenerate old work. Manual Backup/Restore is outside the application under C-12/D-31.
- Subscribing to a Domain event type never grants a Domain event/plugin/SSE consumer unprojected original Payload. Field permissions remain bound to the domain data context.

## AP-02 Common Schemas and Limits

These are selected documentary contract values, explicitly confirmed for AP-02, not benchmarks or SLA. Configuration may lower resource limits; raising them is an explicit operator change subject to validated runtime capacity and advertised compatibility. Exceeding a limit produces `RESOURCE_LIMIT`/`INVALID_INPUT`, not truncation or partial success.

| Boundary | Version 1 contract |
| --- | --- |
| Transport | REST JSON, UTF-8, `schemaVersion: 1`; all timestamps RFC 3339 with offset, output UTC except preserved evidence offset. Binary Payload uses base64; Protocol numeric strings/leading zeros remain strings. Unknown required schema/type is rejected. No OpenAPI artifact generated before AP-04. |
| Submission | Maximum encoded body 1 MiB, at most 1024 Transmission targets; `submissionId` nonempty, at most 128 UTF-8 bytes. Gateway identity comes from authentication, never a trusted caller-supplied ID. `protocol`, `observationTime`, `payload`, `transmissionTargets` required; optional `gatewayNetworkIdentifier`, `qualityMetrics`, `incomplete`. No reported Address means an empty target list, not a fabricated target. |
| References | Gateway/Network/Transmission/Transmission-target/Message/Message-contribution/Unit/Principal IDs are UUID strings; Gateway Network identifiers are exact Gateway-local nonempty strings, at most 128 UTF-8 bytes. A Transmission target can instead use an immutable position within its Transmission; no separate Assignment entity is implied. Internal counters/revisions are nonnegative integers serialized as decimal strings when exceeding JSON safe-integer range; comparisons never use floating-point approximations. |
| Request / paging | Ordinary call deadline 30 s; pages default 50, maximum 200. SSE connection lifetime is not a 30 s ordinary request; individual projection work remains cancellable/bounded. Filter/value lists at most 1024 entries, input nesting 32. |
| Plugin / Workflow | Wasm memory 64 MiB per invocation; input 1 MiB, output 256 KiB, invocation/host I/O deadline 30 s. Workflow maximum 128 steps, nesting 32, collections 1000 elements, regex pattern 4096 UTF-8 bytes, input 1 MiB, 1 s total built-in evaluation budget. All limits include host-call/result allocation; no unbounded fan-out. Trusted optional host processes require their own operator-approved limits; these are not a malicious-code isolation promise. |
| Jobs | Lease 60 s, renew every 20 s; every state write requires current Fencing token and unexpired lease. Authority clock is the primary-store clock, not a Worker's wall clock. |
| Gateway state | Expected heartbeat every 60 s; contact lost after 180 s without authenticated heartbeat/Submission. Configurable positive durations; explicit termination is distinct, never-seen remains distinct. Degraded records reported failure/processing problems; successful new contact ends contact-lost/stopped, without inventing a cause. Last Transmission and heartbeat remain separate. |
| Mutable commands | `expectedRevision` required for update/delete/activation. Revision conflicts never silently overwrite. Create-with-side-effects and bulk commands require a caller-bound idempotency reference, retain result while dependent work exists (at least 24 h); after expiry return expired conflict for known expired commands, never pretend an unrecorded external effect is absent. |

**Uniform interface review:** Unless overridden below, a producer supplies authenticated context plus schema version/domain input; the owning domain validates current C-06 permissions and expected revision, commits domain changes plus C-08 facts/jobs atomically, and returns reference/revision/status or a C-07 error. Consumers use immutable references and current authorized projections, not foreign table writes. Reads are side-effect-free; cancellations after possible commit return uncertainty. Side-effect retries use their operation identity; internal consumers deduplicate by Domain event ID plus consumer identity. C-01 retains its separately confirmed Submission retention exception.

**Revision checks without overengineering:** Use one authoritative access/configuration revision and an affected Assignment scope revision, with ordinary primary-store transactions. Unchanged revisions permit reuse of prepared safe projections; changed relevant revisions require re-evaluation. No distributed per-field consensus or historical permission engine. Revisions are internal proof, not public counters leaking hidden changes. Full instances losing current authority pause private output and attempts; already handed-off bytes/effects are not recallable.

# Freeze Requirements

Per contract: concrete data/error/version forms, named ownership, producer/consumer agreement, current permission/field projection, time/revision, idempotency/retention, transaction/failure boundaries, and concrete positive/negative fixtures. Resolve P-08/P-12/P-14 and relevant technical validation before affected implementation packages. Define language-independent codes and English text/parameter mapping for C-07/C-11 without requiring additional translations. External REST/SDK contracts get machine-readable artifacts only after these gates; this documentation does not pretend they exist.
