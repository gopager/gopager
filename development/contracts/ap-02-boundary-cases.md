| F-36 / [C-10](c-10-plugin-host.md) | Prebuilt plugin digest p1 runs while p2 activates; p1 disabled; a Delivery manifest declaring Core reads; a referenced Secret file's digest changes; webhook DNS resolves metadata address or redirects across authority. | No source build/Core rebuild. | F-37 / [C-11](c-11-processing-presentation.md) | Two Workflows select T and both declare field `level`; one completes, one fails; preview includes an external/command-capable installed step; regex uses lookbehind; late old-version result tries publication. | Fields stay separately namespaced; one result never overwrites another.
