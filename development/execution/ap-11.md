### E-11 Impact of the reviewed AP-10 changes and security review

Date: 2026-11-10. At the user's request, the AP-10 changes between the AP-11 baseline `b164044` and `64c3953` (`e8ac594`, `bbd8024`, `cd8f2cd`, `64c3953`; AP-10 E-09..E-12, D-147) were reviewed for their effect on AP-11 beyond the build, together with two automated security findings on the pushed commit.

Tests `TestDeliveryFollowsAMergeBeforeFanOut`, `TestDeliveryFollowsAMergeBeforeItStarts` (`cmd/gopager/delivery_merge_test.go`); both fail without the fix (checked by stashing `internal/delivery/materialize.go`: `after fan-out: []`, Delivery cancelled) and pass with it.
- **Admission cleanup (AP-10 E-09).** `delivery_admissions` had the defect AP-10 fixed for `search_admissions`: windows of buckets that never return stayed forever. Fixed the same way: each admitted send deletes up to 100 expired windows of any bucket (`FOR UPDATE SKIP LOCKED`), index `delivery_admissions_window_start` in `00013_events_delivery.sql`. Test `TestTakeSendAttemptSweepsExpiredWindowsOfOtherBuckets` (150 expired rows: 50 after one admitted send, 0 after two, current windows kept). `docs/operations.md`, `docs/architecture.md`, C-09 and the handover corrected (they called the table self-pruning).
- **Classification (D-147).** Results of Workflow versions with installed steps are now classified without the plugin instance, so they reach Delivery projections and `result.*` filters regardless of instance state; no AP-11 change needed. The composition-order comment and reordering in `cmd/gopager/main.go` that existed only for the removed `core.classification` override were reverted to AP-10's order. `events.BatchPreparer` stays: warming still opens its own transaction.
- **`TestLiveStreamCutoffHasNoGap`** (E-08 first run) was a flaky assertion that AP-10 fixed in E-09; it was not caused by AP-11.
- **Page-token key, signed positions, before-basis rule:** no effect on AP-11 (Delivery uses neither tokens nor positions; Delivery reads authorize by the Delivery's recorded age anchor).
