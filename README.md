# GoPager

GoPager accepts alarm telegrams with traceable reception records, assigns recipients to units, groups matching receptions technically, and provides authorized search, live views, and explicitly configured notifications.

The new product is designed as a modular monolith in Go. This repository separates it from the PagerMon codebase. It currently contains the documentary specification, not a runnable application.

English is the authoritative project language. Internationalization will be prepared from the first implementation, with English as the only initially required language; no additional translations are required yet.

Start with the [documentation index](docs/README.md). It covers requirements, architecture decisions, domains, contract drafts, and dependent work packages with their approval status. Documentation does not approve unresolved product decisions or authorize product implementation.
